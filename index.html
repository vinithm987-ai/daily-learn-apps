04 / ABOUT

Meet ALVIN AI.

ALVIN AI is a Stage 1 learning and search interface designed to bring searching, explaining and learning into one place.

Important: This Stage 1 version does not contain a private AI model or secure server account system. Registration is a local browser demo, while topic search uses Wikipedia's public API. A real AI API, database authentication and production security can be added in the next stage.
